# Environment & Signing Key Configuration Guide (`ENV-SETUP.md`)

This guide documents all actual environment variables read by the **Central Licensing Server** (`02-licensing/config.php`) and **Client Application** (`01-client/config.php`, `01-client/install.php`, `01-client/bin/license-check.php`), as well as Ed25519 signing key security requirements.

> [!IMPORTANT]
> Production ZIP packages **never** contain real `.env` files or private keys. Each package ships with `.env.example`. Copy `.env.example` to `.env` on the target server and set permissions to `chmod 600 .env`.

---

## 1. Central Licensing Server Environment (`.env`)

Source template: `02-licensing/.env.example`

```ini
# Central Licensing Server Environment Configuration
APP_URL=https://licensing.yourdomain.com
TENANT_ID=1
APP_SECRET=replace-with-64-char-hex-from-openssl-rand-hex-32
CRON_SECRET=replace-with-64-char-hex-from-openssl-rand-hex-32

DB_HOST=127.0.0.1
DB_PORT=3306
DB_NAME=kohevo_licensing
DB_USER=kohevo_licensing_user
DB_PASS=replace-with-strong-database-password
DB_CHARSET=utf8mb4
```

### Central Variable Reference

| Variable | Required | Default in `config.php` | Purpose |
| :--- | :--- | :--- | :--- |
| `APP_URL` | **Yes** | *(fallback URL)* | Public HTTPS base URL of the Central Licensing Server (no trailing slash). Mapped to `SLATE_URL`. |
| `TENANT_ID` | **Yes** | `1` | Tenant context ID for the Central Licensing Server (`1`). |
| `APP_SECRET` | **Yes** | `''` (fails closed) | 32-byte (64 hex char) cryptographic secret used by `slate_encrypt_secret()` / `slate_decrypt_secret()` (AES-256-GCM) and `slate_sign()` (HMAC-SHA256). Encrypts the Central Ed25519 secret signing key at rest in `settings`. |
| `CRON_SECRET` | **Yes** | `''` (fails closed) | Shared secret required in the `X-Cron-Key` header (or `?key=`) when invoking `cron.php`. |
| `DB_HOST` | **Yes** | `localhost` | MySQL / MariaDB hostname or IP (`127.0.0.1` recommended). |
| `DB_PORT` | Optional | `''` (driver default `3306`) | MySQL / MariaDB port. |
| `DB_NAME` | **Yes** | `slate` | Central database name (e.g. `kohevo_licensing`). |
| `DB_USER` | **Yes** | `slate` | Central database username. |
| `DB_PASS` | **Yes** | `''` | Central database password. |
| `DB_CHARSET` | Optional | `utf8mb4` | Database connection character set (`utf8mb4`). |
| `MCP_GATEWAY_ENABLED` | Optional | `0` | Kill switch for MCP gateway (`0` = disabled by default). |

### Central Signing Configuration

The Central Licensing Server does **not** store its Ed25519 private signing key in `.env` or in a plaintext file on disk. Instead:
- Running `php bin/licensing-generate-keys.php` generates an Ed25519 keypair via `sodium_crypto_sign_keypair()`.
- The public key is stored in `settings` (`setting_key = 'licensing.signing_public_key'`) and printed to stdout.
- The private (secret) key is encrypted using `slate_encrypt_secret()` (AES-256-GCM keyed off `APP_SECRET`) and stored in `settings` (`setting_key = 'licensing.signing_secret_key'`).

```ini
DB_HOST=127.0.0.1
DB_PORT=3306
DB_NAME=kohevo_client
DB_USER=kohevo_client_user
DB_PASS=replace-with-strong-database-password
DB_CHARSET=utf8mb4

# Central Licensing Server Configuration
LICENSE_SERVER_URL=https://licensing.yourdomain.com
LICENSE_SERVER_PUBLIC_KEY=YOUR_ED25519_PUBLIC_KEY_BASE64_HERE

LICENSE_KEY=KOH-XXXX-XXXX-XXXX-XXXX
```

| Variable | Required | Written / Updated By | Purpose |
| :--- | :--- | :--- | :--- |
| `APP_URL` | **Yes** | Operator or Installer Step 1 | Public HTTPS base URL of the Client Application (no trailing slash). Mapped to `SLATE_URL`. |
| `TENANT_ID` | **Yes** | Installer Step 2 (or `.env`) | Database-resolved tenant ID (`0` before install, `1` after provisioning). |
| `INSTALLATION_ID` | Auto | Installer Step 2 | 32-character lowercase hex unique installation identity generated by `InstallationService::provisionCore()`. Persisted in both `installation_identity` table and `.env` so database recovery reuses the same ID. Never manually fabricate or clone across servers. |
| `APP_SECRET` | **Yes** | Operator or Installer Step 1 | 32-byte (64 hex char) cryptographic secret for AES-256-GCM secret encryption and HMAC signing on this client install. Must be unique per installation. |
| `CRON_SECRET` | **Yes** | Operator or Installer Step 1 | Shared secret required in `X-Cron-Key` header when invoking `cron.php`. Must be unique per installation. |
| `DB_HOST` | **Yes** | Operator or Installer Step 1 | Client MySQL / MariaDB host (`127.0.0.1`). |
| `DB_PORT` | Optional | Operator or Installer Step 1 | Client MySQL / MariaDB port (`3306`). |
| `DB_NAME` | **Yes** | Operator or Installer Step 1 | Client database name. |
| `DB_USER` | **Yes** | Operator or Installer Step 1 | Client database username. |
| `DB_PASS` | **Yes** | Operator or Installer Step 1 | Client database password. |
| `DB_CHARSET` | Optional | `utf8mb4` | Database character set (`utf8mb4`). |
| `LICENSE_SERVER_URL` | **Yes** | Operator / Provider | Base HTTPS URL of the Central Licensing Server (e.g. `https://licensing.yourdomain.com`). |
| `LICENSE_SERVER_PUBLIC_KEY` | **Yes** | Operator / Provider | Base64-encoded Ed25519 public key from Central (`php bin/licensing-generate-keys.php`). Used by `LicenseSignatureVerifier` to verify signed responses and cached envelopes. |
| `LICENSE_PRODUCT` | **Yes** | Operator / Provider | Product slug registered on Central (`kohevo`). |
| `LICENSE_KEY` | **Yes** | Installer Step 3 / `/admin/license.php` / Operator | Commercial license key assigned to this client installation. Automatically persisted to `.env` upon successful validation so `php bin/license-check.php` can run unattended. |
| `MCP_GATEWAY_ENABLED` | Optional | `0` | Kill switch for MCP gateway (`0` = disabled by default). |

## 3. Signing Key Security Lifecycle

### 3.1 Key Generation (Central Server Only)

Run once on the Central Licensing Server after database migration:

```bash
php bin/licensing-generate-keys.php
```

- Requires `ext-sodium`.
- Generates an Ed25519 keypair.
- Prints **only** the Base64-encoded public key.
- Refuses to overwrite an existing keypair unless `--force` is explicitly passed.

### 3.2 Private Key Storage

- The Ed25519 secret key is encrypted via `slate_encrypt_secret()` (AES-256-GCM keyed with `APP_SECRET`) and stored in the Central database `settings` table under `licensing.signing_secret_key`.
- The plaintext secret key is never written to disk, never logged, and never included in any API response or deployment package.

### 3.3 Public Key Distribution to Client

- Retrieve the public key on Central at any time:
  ```bash
  php -r 'require "config.php"; require_once "plugins/licensing/LicensingAPI.php"; echo LicensingAPI::signingPublicKey() . "\n";'
  ```
- Embed the resulting Base64 string in the Client `.env` as `LICENSE_SERVER_PUBLIC_KEY`.
- The public key is safe to distribute to client installations; it can only **verify** signatures, never create them.

### 3.4 File Permissions

On both Central and Client servers:

```bash
chmod 600 .env
chmod 640 .installed
```

### 3.5 Backup & Recovery of Signing Material

- Back up Central's `APP_SECRET` (from `.env`) alongside regular backups of Central's `settings` table (`licensing.signing_public_key` and `licensing.signing_secret_key`).
- **Critical Warning:** If Central's `licensing.signing_secret_key` or `APP_SECRET` is lost and a new keypair must be generated with `--force`, every deployed Client Application will reject new check-in responses (`signature_invalid`) until the new `LICENSE_SERVER_PUBLIC_KEY` is deployed to their `.env`.
